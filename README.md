# DSL TMS v01

운송관리시스템(TMS) 기준 정보 등록 프로토타입입니다. 별도 백엔드 없이 브라우저의 `localStorage`에 데이터를 저장하며, 초기 업무 흐름 검증과 화면 논의에 사용할 수 있습니다.

## 지원 등록 항목

1. 거래처 등록
2. 센터 등록
3. 사업주 등록
4. 운전자 등록
5. 차량 등록
6. 차량 제원 등록
7. 차량 배정 등록
8. 보험 등록
9. 점검 등록
10. 계약 등록
11. 사진 업로드

## 실행

```bash
npm start
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 테스트

```bash
npm test
```

## 구성

- `index.html`: 등록 콘솔 화면
- `styles.css`: 반응형 화면 스타일
- `src/modules.js`: 등록 항목별 입력 필드 정의
- `src/storage.js`: 로컬 저장소 기반 등록/삭제 로직
- `src/app.js`: 화면 렌더링과 입력 처리
